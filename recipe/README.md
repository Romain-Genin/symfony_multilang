# Symfony Flex recipe

Files to submit to [symfony/recipes-contrib](https://github.com/symfony/recipes-contrib)
under `romain-genin/symfony-multilang-bundle/1.0/` once the package is published on Packagist.

They are also used by `php bin/console multilang:install`, which does the same job
(plus the `config/routes.yaml` prefix) for projects that do not use contrib recipes.
